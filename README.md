# 작은 용사의 숲: 별빛 원정대 — 온라인 테스트 버전

## 설치와 실행
Node.js 18 이상 설치 후, 프로젝트 폴더에서 `npm start`를 실행합니다. 외부 패키지 설치는 필요하지 않습니다.
브라우저에서 `http://localhost:3000`에 접속합니다. 같은 와이파이의 다른 기기는 `http://PC의_내부IP:3000`으로 접속할 수 있습니다(Windows 방화벽 허용 필요).

## 외부 테스터 동시 접속
공인 HTTPS 주소에서 운영하려면 Node.js를 지원하는 서버에 이 폴더를 배포하고 `npm start`를 실행합니다. 배포 플랫폼의 영구 저장 볼륨을 `data/`에 연결해야 계정/게임 저장이 재배포 후에도 유지됩니다. 각 테스터가 직접 계정을 생성하거나 운영자가 계정을 생성해 ID/비밀번호를 전달합니다. 현재 서버는 계정별 독립 진행 및 접속자 수 표시를 지원하며 실시간 협동 전투는 지원하지 않습니다.

## 보안 및 운영 유의
본 버전은 **소규모 비공개 테스트용**입니다. 운영 전 HTTPS, 가입 제한/초대 코드, 요청 속도 제한, 영구 DB(PostgreSQL 등), 백업, 비밀번호 재설정, 세션 영구 저장을 추가하세요. 서버 재시작 시 세션이 해제되며 재로그인하면 저장 데이터는 유지됩니다. `data/players.json`에는 비밀번호 원문 대신 scrypt 해시가 저장됩니다. 테스트용 서버를 인터넷에 무방비로 공개하지 마세요.

## 게임 내용
자동 전투, 챕터 4종, 보스 자동 도전, 장비 5부위, 등급별 드롭, 레벨별 분해, 공격/체력 강화, 일괄 강화, 동료 6종/2명 편성, 펫 6종/1마리 편성, 1회/10회 뽑기, 10회 영웅 이상 보장, 별빛 베기, 오프라인 골드 보상, Canvas 벡터 그래픽 및 Web Audio 효과음, 계정별 저장.

## 한계
그래픽은 자체 Canvas 일러스트/애니메이션 기반으로, 상용 게임 수준의 아트 에셋과 완성된 BGM은 아닙니다. 뽑기 희귀도는 결과 표시용이며 동일 동료의 성급 강화는 향후 밸런스 조정이 필요합니다. 서버는 저장된 플레이 데이터를 신뢰하므로 경쟁/유료 게임 운영에 적합하지 않습니다.
