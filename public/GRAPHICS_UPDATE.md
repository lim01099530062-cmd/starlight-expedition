# 애니메이션풍 전투 화면 v2

- 기존 로그인, 전투, 성장, 저장 API는 유지합니다.
- 새 전투 일러스트: `public/anime_battle.png`
- 동적 타격 이펙트 및 데미지 수치: `public/game.js`
- 게임 화면 테마: `public/style.css`

## GitHub 업로드
기존 GitHub 저장소에서 `public/game.js`, `public/style.css`를 새 파일로 덮어쓰고 `public/anime_battle.png`를 추가합니다. 서버 파일을 변경할 필요는 없습니다.

## 참고
현재 v2는 **통합 일러스트 기반 전투 장면**이며 캐릭터별 개별 스프라이트 애니메이션은 아닙니다. 기존 전투 수치와 온라인 계정 기능은 변경하지 않았습니다.
